## Русский

Этот репозиторий содержит коллекцию небольших макросов на [AutoHotkey](https://www.autohotkey.com/) для различных игр.

Большинство этих макросов изначально создавались для моих личных нужд — чтобы упростить или автоматизировать различные рутинные действия, которые возникали у меня во время прохождения игр. Как правило, каждый скрипт решает одну конкретную небольшую задачу.

Я решил выложить некоторые из них в открытый доступ на случай, если они окажутся полезны кому-нибудь ещё. Вы можете свободно использовать, изменять, адаптировать и перерабатывать эти макросы под свои нужды.

### Перед использованием

Каждый `.ahk` файл содержит собственное описание и настройки. **Перед первым запуском любого макроса рекомендуется открыть файл в текстовом редакторе и ознакомиться с информацией в его начале.**

Там обычно указано, для чего предназначен макрос, как его использовать и какие настройки доступны для изменения.

Также в репозитории может присутствовать файл `Settings.ahk` с общими настройками, используемыми несколькими макросами. Если в конкретном макросе присутствует настройка с таким же именем, как в `Settings.ahk`, приоритет имеет значение, указанное непосредственно в файле макроса.

## English

This repository contains a collection of small [AutoHotkey](https://www.autohotkey.com/) macros for various games.

Most of these macros were originally created for my own needs — to simplify or automate various routine tasks that I encountered while playing games. In most cases, each script is designed to solve one specific small problem.

I decided to make some of them publicly available in case they might be useful to someone else. Feel free to use, modify, adapt, or reuse these macros for your own needs.

### Before using a macro

Each `.ahk` file contains its own description and settings. **Before running any macro for the first time, it is recommended to open the file in a text editor and read the information at the beginning of the script.**

The description usually explains what the macro does, how to use it, and which settings are available.

The repository may also contain a `Settings.ahk` file with common settings used by multiple macros. If a particular macro contains a setting with the same name as one in `Settings.ahk`, the setting defined directly in the macro file takes priority.
